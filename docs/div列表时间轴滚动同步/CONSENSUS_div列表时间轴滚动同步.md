# div 列表时间轴滚动同步 - 需求共识文档

## 确认的需求

### 功能需求
1. **时间轴滚动同步**：当用户左右滚动日历表格内容时，时间轴头部（时间段列）需要与内容区域保持同步滚动
2. **设备列固定**：保持设备名称列（第一列）的固定功能，确保用户始终能看到设备信息

### 技术约束
- 基于现有项目结构和代码风格实现
- 使用React框架和TypeScript
- 表格组件使用Semi UI的Table组件

## 验收标准

1. **滚动同步**：
   - 当用户水平滚动表格时，时间轴头部（时间段列）应与内容区域保持同步滚动
   - 用户可以清晰看到当前查看的时间段

2. **设备列固定**：
   - 设备名称列应保持固定，不随水平滚动移动
   - 确保在任何滚动位置都能看到设备名称

3. **页面功能**：
   - 修改不应影响现有的表格功能，如单元格点击、悬浮效果等
   - 保持表格整体布局和样式的一致性

## 技术方案

### 实现方式
1. **修改表格列配置**：
   - 保留设备列的`fixed: "left"`属性
   - 移除所有时间段列的`fixed: "left"`属性，允许它们随内容区域滚动

2. **调整样式（如需）**：
   - 确保滚动同步后的表格视觉效果良好
   - 可能需要微调表格布局以适应滚动行为的变化

3. **验证方法**：
   - 手动测试水平滚动功能，确认时间轴头部与内容区域同步滚动
   - 确认设备列保持固定
   - 验证所有现有功能正常工作
