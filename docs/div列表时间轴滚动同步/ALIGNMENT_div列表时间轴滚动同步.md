# div 列表时间轴滚动同步 - 需求对齐文档

## 原始需求
> `div` 列表左右滚动时间轴不随着滚动

## 问题分析
根据用户提供的信息和当前项目状态，我们需要解决一个UI交互问题：

1. 当前系统实现了一个日历表格界面，显示设备预约情况
2. 表格包含固定的设备列和横向滚动的时间轴列
3. 问题表现为：当用户左右滚动列表内容时，时间轴头部不跟随同步滚动，导致用户无法知道当前查看的是哪个时间段
4. 从DOM结构可以看到，当前使用了 `semi-table-wrapper` 和 `semi-table` 组件，且设置了固定列 `semi-table-cell-fixed-left`

## 任务范围

### 要做的事
1. 修复时间轴头部与内容区域的滚动同步问题
2. 确保当用户横向滚动时，时间轴头部能够与内容区域保持一致的滚动位置
3. 保持设备列的固定功能

### 不做的事
1. 不改变现有的整体布局结构
2. 不修改时间格式或显示内容
3. 不调整固定的设备列功能
