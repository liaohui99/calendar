# 共识文档：div按钮失焦报错

## 需求确认
我们确认问题是由于React 19与Semi UI 2.27.0之间的兼容性导致的。React 19移除了`findDOMNode`方法，而Semi UI组件内部仍在使用此方法，导致点击下拉框等元素外部时出现错误。

## 验收标准
1. 点击Select等下拉框后，再点击外部区域，下拉框能正常关闭且不再报错
2. 控制台中不再出现`findDOMNode`相关的警告或错误
3. 项目可以正常构建，无编译错误
4. 所有UI组件功能正常，不影响用户体验

## 技术方案
最佳解决方案是将React版本从19.x降级到18.2.0，因为：
1. Semi UI 2.27.0与React 18.2.0完全兼容
2. 这是最小侵入性的解决方案，不需要修改组件代码
3. 可以快速解决当前的兼容性问题

具体步骤：
1. 修改package.json，将React和相关依赖版本降级
2. 重新安装依赖
3. 验证问题是否解决

## 风险评估
- 降级React版本可能需要调整部分使用了React 19特有功能的代码，但从项目现状看，风险较低
- 重新安装依赖可能会引入其他依赖冲突，但使用`--legacy-peer-deps`可以缓解这个问题
