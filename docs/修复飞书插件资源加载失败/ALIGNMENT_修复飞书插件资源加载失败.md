# 修复飞书插件资源加载失败 - 需求对齐

## 原始需求
> 飞书插件中打开设备预约页面'tab-web'，显示资源加载失败

## 任务范围

### 包含内容
- 分析飞书插件中'tab-web'资源加载失败的原因
- 修复配置文件中的不匹配问题
- 重新构建项目确保正确生成资源文件
- 验证修复是否成功

### 不包含内容
- 修改前端UI或业务逻辑
- 优化构建输出大小
- 修改其他功能模块

## 问题分析
经过检查发现，问题出在配置文件之间的不一致性：
- `plugin.config.json` 中定义的资源ID为 `tab-web`
- `vite.config.ts` 中为该资源生成的输出文件名为 `tab-resource-web.js`

这种命名不匹配导致飞书插件在尝试加载资源时找不到正确的文件名，从而显示资源加载失败。

## 技术方案
1. 修改 `vite.config.ts` 中的输出文件名配置，将 `tabWorkItemPage` 的输出文件名从 `tab-resource-web.js` 改为 `tab-web.js`
2. 重新构建项目以生成正确命名的输出文件
3. 验证构建输出是否包含正确命名的文件

## 验收标准
- 构建成功，生成的文件名与配置文件中的资源ID一致
- 飞书插件能够成功加载'tab-web'资源
- 设备预约页面能够正常显示
