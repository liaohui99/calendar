## 确认需求

前端页面在运行时出现以下错误：
1. React 19 中 element.ref 的使用已被移除，需要调整引用方式
2. 日期格式化中仍存在使用 `YYYY` 代替 `yyyy` 的问题

## 验收标准
1. 前端服务能够正常启动并访问
2. 浏览器控制台不再显示 element.ref 相关错误
3. 浏览器控制台不再显示 YYYY 日期格式化相关错误
4. 所有功能模块能够正常工作，没有因修复导致的新问题

## 技术方案
1. 全面检查 Semi UI 组件的使用方式，特别是涉及 ref 的部分
2. 对前端代码中的所有日期格式化进行地毯式搜索和修复
3. 修改完成后重启服务并验证修复效果
