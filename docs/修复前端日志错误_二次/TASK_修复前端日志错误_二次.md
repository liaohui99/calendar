- **依赖关系**: 无

### T2: 修复 Semi UI 组件中的 ref 使用问题

- **输出**: 修复后的组件代码
- **实现约束**: 遵循 React 19 的 ref 使用规范
- **依赖关系**: T1

### T3: 全面搜索前端代码中的 YYYY 日期格式化

- **输出**: 所有使用 YYYY 进行日期格式化的文件和位置

- **依赖关系**: 无

### T4: 修复所有 YYYY 日期格式化问题

- **输出**: 修复后的日期格式化代码
- **实现约束**: 将所有 YYYY 替换为 yyyy
- **依赖关系**: T3

### T5: 验证修复效果
- **输入**: 修复后的前端代码
- **输出**: 验证报告
- **实现约束**: 重启前端服务，检查控制台日志
