# 需求共识文档：修复日期选择器年份显示错误

## 确认的需求
修复前端组件中的日期格式化问题，确保当用户通过input选择具体日期时，传给后端的是正确的日期格式（如"2023-10-05"），而不是错误的格式"yyyy-10-05"。

## 技术方案
通过分析代码，发现问题在于不同组件中使用了不一致的日期格式化字符串。在DeviceReservationPage.tsx中，selectedDate状态初始化为`dayjs().format('yyyy-MM-DD')`，而在其他地方也有类似的格式。根据dayjs库的规范，年份应该使用大写的'YYYY'。

解决方案：
1. 统一项目中所有组件的日期格式化字符串，统一使用小写的'yyyy'（根据现有代码风格）
2. 检查并修复所有使用日期格式化的地方，确保一致性
3. 进行测试验证

## 验收标准
1. 当用户在日期选择器中选择日期后，API请求中传递的日期参数应包含实际年份（如"2023-10-05"），而不是"yyyy-10-05"
2. 前端页面正确显示所选日期
3. 后端API能够正确处理日期参数并返回相应数据
4. 所有相关组件功能正常，无报错
