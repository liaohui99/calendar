# 需求对齐文档：修复日期选择器年份显示错误

## 原始需求
用户报告：
- 刷新页面调用接口错误：http://localhost:5173/api/reservations?date=yyyy-10-24，date应该是当前具体的年月日，例如2025-10-24
- 点击input选择日期的时候，传的年也是yyyy，应该是具体选择的年份

## 任务范围

### 包含内容
1. 修复日期选择器中年份显示为"yyyy"而不是实际年份的问题
2. 确保传递给API的date参数包含正确的年份格式（YYYY-MM-DD）
3. 验证在页面刷新和选择日期时，日期格式是否正确
4. 确保CalendarView组件能正确处理日期参数并加载相应数据

### 不包含内容
1. 修改日期选择器的外观样式（除非必要）
2. 更改日期格式的整体布局或交互方式
3. 修改后端API的日期处理逻辑

## 疑问清单

1. 日期选择器组件是自定义的还是使用第三方库（如Semi UI的DatePicker）？
2. 当前的日期状态管理是在哪个组件中实现的？
3. 刷新页面时，日期是如何被初始化的？
4. 是否有特定的年份限制或验证规则？
5. 是否需要支持多语言或不同地区的日期格式？

## 初步分析

根据用户描述，问题出在日期选择器组件中，年份显示为"yyyy"占位符而不是实际的年份值。这可能是由于：

1. 日期初始化逻辑有问题，没有正确设置默认年份
2. 日期格式化或解析过程中出现错误
3. DatePicker组件的配置不正确
4. 状态管理中日期格式不一致

需要进一步检查相关组件代码，特别是FilterComponent中的日期选择器实现和日期处理逻辑。
