# 下拉框点击外部关闭功能需求对齐

## 原始需求
用户提出："div div 点击下拉框，再点击下拉框外，要求移除展开的下拉框"

## 任务范围

### 包含内容
1. 实现下拉框组件的点击外部关闭功能
2. 确保点击下拉框本身不会关闭下拉框
3. 确保在整个应用中所有类似的下拉框组件都具备此功能
4. 保持现有UI交互的一致性和流畅性

### 不包含内容
1. 下拉框内部的样式修改
2. 下拉框的动画效果增强
3. 非下拉框组件的交互逻辑修改

## 疑问清单

1. 当前项目使用的是哪个UI库的下拉框组件？从现有标签来看，似乎使用了semi.design库的Select组件
2. 下拉框组件的相关代码位于哪些文件中？
3. 是否需要考虑移动端的触摸事件？
4. 下拉框的展开状态是如何管理的？是通过state、props还是其他方式？

## 初步假设
1. 项目使用了semi.design UI库，需要检查相关组件的配置或进行自定义扩展
2. 实现方式可能涉及事件委托、点击事件监听和状态管理
3. 需要确保在处理点击外部事件时不会干扰页面上其他交互元素
4. 实现应该遵循React组件的最佳实践，避免内存泄漏
