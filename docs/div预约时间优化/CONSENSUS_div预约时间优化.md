# 需求共识文档 - div预约时间优化

## 确认需求

1. **功能修改**：删除设备预约表单中独立的"预约日期"字段，修改开始时间和结束时间选择器，使其同时展示和选择日期和时间
2. **数据结构**：调整表单数据结构，使开始时间和结束时间字段包含完整的日期时间信息
3. **技术实现**：使用Semi-UI的DatePicker组件，调整为日期时间选择模式
4. **业务逻辑**：确保表单验证和数据提交逻辑适应新的数据格式

## 验收标准

1. 预约表单中不再显示独立的"预约日期"字段
2. 开始时间和结束时间选择器能够同时选择日期和时间
3. 表单数据正确处理和提交，包含完整的日期时间信息
4. 所有相关测试用例通过
5. 界面样式与整体风格保持一致，无布局问题

## 技术方案

1. 修改GeneralReservationForm.tsx组件：
   - 删除"预约日期"字段的DatePicker组件
   - 修改开始时间和结束时间的DatePicker组件配置，使其同时显示日期和时间
   - 调整handleDateChange和handleTimeChange函数以适应新的数据格式
   - 更新表单验证逻辑

2. 数据处理：
   - FormData接口中的date字段将被移除
   - startTime和endTime字段将存储完整的日期时间字符串
   - 确保与后端API的兼容性

3. 测试验证：
   - 编写测试用例验证新的时间选择功能
   - 运行现有测试确保无回归问题
