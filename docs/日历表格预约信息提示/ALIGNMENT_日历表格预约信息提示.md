# 日历表格预约信息提示 - 需求对齐文档

## 原始需求

鼠标悬停已预约的表格中，需要将预约人和预约信息提示出来。

## 任务范围

### 包含内容
1. 优化已预约单元格的悬停提示功能
2. 显示更完整的预约信息，包括但不限于：预约人姓名、联系方式、预约时间段、预约事由、预约状态等
3. 确保提示信息格式清晰、易读
4. 避免React警告（findDOMNode is deprecated）

### 不包含内容
1. 修改后端API
2. 更改现有数据模型
3. 添加新的数据字段

## 疑问清单

| 疑问 | 假设 | 确认状态 |
|------|------|----------|
| 需要显示哪些具体的预约信息字段？ | 显示预约人姓名、联系方式、时间段、事由、状态 | 待确认 |
| 提示信息的样式有何特殊要求？ | 使用默认的Tooltip样式，确保文字换行显示 | 待确认 |
| 是否需要支持点击操作？ | 仅实现悬停提示，不包含点击交互 | 待确认 |

## 初步假设

1. 现有系统中已有基本的Tooltip实现，但仅显示预约人姓名和事由
2. Reservation接口中包含完整的预约信息
3. 需要解决React的findDOMNode弃用警告问题
4. 使用semi.design的Tooltip组件来实现提示功能
