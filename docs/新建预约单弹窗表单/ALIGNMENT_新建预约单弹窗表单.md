# 新建预约单弹窗表单 - 需求对齐文档

## 原始需求
用户点击"新建预约单"按钮，弹窗显示预约单提交表单，让用户手动输入时间及设备信息。

## 任务范围

### 包含内容
1. 实现点击"新建预约单"按钮的交互逻辑
2. 设计并实现预约单弹窗组件
3. 实现预约表单，包含时间选择和设备选择功能
4. 表单验证逻辑
5. 提交预约数据到后端的功能
6. 成功/失败提示信息

### 不包含内容
1. 不需要实现复杂的权限控制
2. 不需要实现预约冲突检测（假设后端会处理）
3. 不需要修改现有UI样式风格

## 疑问清单

1. 预约表单是否需要包含用户信息字段？
2. 时间选择是否需要支持时间段选择（开始时间和结束时间）？
3. 设备选择是否支持多选？
4. 是否需要保存用户上次选择的偏好？
5. 表单提交成功后是否需要自动关闭弹窗？

## 技术假设

1. 前端使用React + TypeScript开发
2. UI组件使用semi.design组件库
3. 表单验证使用React Hook Form或semi组件内置验证
4. 与后端通信使用fetch或axios
5. 弹窗使用semi的Modal组件
