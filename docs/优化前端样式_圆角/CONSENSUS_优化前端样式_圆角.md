# 需求共识：为span元素添加圆角样式

根据分析和初步修改，确认以下需求：

1. 将日历图标从简单的span元素（📅）替换为semi.design的Tag组件，并添加8px的圆角样式
2. 为"新建预约单"按钮添加8px的圆角样式
3. 保持整体设计风格的一致性和美观性

1. 页面上的日历图标显示为带有圆角的Tag组件

3. 所有修改后的组件符合semi.design的设计规范
4. 页面功能正常，无错误或异常行为
5. 构建成功，无编译错误

1. 使用semi.design的Tag组件替换日历图标span元素
